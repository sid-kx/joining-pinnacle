# Pinnacle Realty Recruiting Landing Page

A standalone HTML/CSS/JavaScript recruiting site inspired by the conversion rhythm and editorial structure of agentattraction.io, rebuilt with original Pinnacle Realty branding, copy, UI, and placeholder content.

## Files
- `index.html` — page structure/content
- `style.css` — all visual styling and responsive behavior
- `script.js` — navigation, reveal animation, counters, drag rail, review slider, FAQ, and demo form behavior

## Before production
1. Replace sample agent quotes/testimonials with approved, authentic Pinnacle content.
2. Replace placeholder video cards with real thumbnails/embeds.
3. Connect `#applicationForm` to your CRM/form endpoint.
4. Add your real privacy policy / terms URLs.
5. Add approved Meta Pixel / GTM snippets if required.
6. Replace the inline geometric Pinnacle mark with your official logo if desired.

## Run locally
Open `index.html` directly, or serve the folder with any static server.
